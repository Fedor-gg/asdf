Дефект 1: Функция Grade (оценка 85 баллов)
Что было сломано: В исходном коде использовалось строгое неравенство: if (score > 85) return "5";. 
Почему тест это поймал: Спецификация из ПР28 определяет диапазон для оценки "5" как "85–100". Математически и логически это означает, что граница 85 включена в интервал. Оператор "больше" (>) является строгим и исключает граничное значение из проверки. 
Когда тест Grade(85) передал в функцию число 85, условие 85 > 85 оказалось ложным. Программа провалилась в предыдущую ветку условий, которая проверяла диапазон для оценки "4" (вероятно, if (score < 85) или if (score <= 84)), и вернула строку "4". 
Тест зафиксировал несоответствие: ожидалось "5" по спецификации, получено "4". Тест сработал как предохранитель на граничном значении, выявив потерю края диапазона.
Как исправлено: Условие заменено на нестрогое: if (score >= 85) return "5";. Теперь число 85 удовлетворяет условию, и функция возвращает верную оценку.

Дефект 2: Функция CheckPassword (пароль "a1b2cD3f")
Что было сломано: Проверка наличия заглавной буквы выполнялась только для первого символа строки: char.IsUpper(password[0]). 
Почему тест это поймал: Спецификация требует наличия хотя бы одной заглавной буквы в любом месте строки, а не только в начале. Тестовый кейс "a1b2cD3f" имеет длину 8 символов (проходит проверку на длину), содержит цифру (проходит проверку hasDigit), а заглавная буква 'D' находится на 6-й позиции. 
Поскольку первый символ пароля — строчная 'a', функция char.IsUpper(password[0]) вернула false. Программа сразу выдала ошибку "Нет заглавной буквы", даже не проверив остальные 7 символов. 
Тест ожидал "OK", так как все формальные требования спецификации (длина, наличие цифры, наличие заглавной буквы) были выполнены. Тест поймал дефект реализации алгоритма поиска — проверку не по всей строке, а по единственному индексу.
Как исправлено: Вместо проверки одного символа добавлен цикл, который итерируется по всей строке (например, foreach (char c in password)). Внутри цикла выставляется флаг hasUpper = true, если встречается заглавный символ, после чего поиск прекращается (break). Это гарантирует корректную проверку наличия заглавной буквы в любой позиции.
